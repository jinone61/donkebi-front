# 미국 개장일 예정 표시 폴백 설계

## 목적

Agent Operation 화면은 API가 제공한 `targetDate`만 표시하므로, 최신 거래일의 네 단계가 모두 끝난 뒤 다음 거래일의 첫 작업이 생성되기 전에는 예정 카드가 보이지 않는다. 서버가 다음 일정을 제공하지 않는 경우에만 프런트에서 다음 미국 개장일을 계산해 예정 흐름 한 묶음을 표시한다.

## 동작

- API 최신 날짜에 `PREPARE`, `APPLY`, `PLAN`, `SUBMIT` 기록이 모두 있으면 다음 미국 개장일을 계산한다.
- 계산한 날짜의 예정 단계 네 개를 화면 최상단에 추가한다.
- 최신 날짜에 누락된 단계가 하나라도 있으면 새 날짜를 추가하지 않고 기존 날짜의 누락 단계만 예정으로 표시한다.
- 예정 시간은 직전 개장일에서 같은 단계가 실제로 시작된 시간을 사용한다.
- 서버가 향후 날짜를 이미 내려주면 해당 날짜를 그대로 사용하며 프런트 폴백 날짜를 중복 생성하지 않는다.

## 미국 개장일 계산

주말과 미국 주식시장의 반복 정규 휴장일을 제외한다. 대상은 신정(대체휴일 포함), MLK Day, Presidents Day, Good Friday, Memorial Day, Juneteenth(대체휴일 포함), Independence Day(대체휴일 포함), Labor Day, Thanksgiving Day, Christmas Day(대체휴일 포함)이다.

국가 애도일, 재난 등 비정기 휴장은 프런트 규칙만으로 신뢰성 있게 판별할 수 없으므로 범위에서 제외한다. 이런 일정은 향후 서버가 `nextTargetDate`를 제공하면 서버 값을 우선한다.

## 구조와 검증

달력 계산은 독립적인 유틸리티로 분리한다. 단위 테스트에서 평일 이동, 금요일에서 월요일 이동, 대체휴일, Good Friday를 검증한다. Agent 화면 테스트에서는 완료된 최신 날짜에만 다음 예정 날짜가 추가되고 진행 중인 최신 날짜에는 추가되지 않는지 확인한다. 마지막으로 lint와 production build를 실행한다.
